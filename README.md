## 双语规范

正文以中文为主体，英文术语以 `English term（中文）` 形式行内嵌入；公式与 LaTeX 环境保留英文原样。

## 学习定位

对应方舟计划大二上「信息论」辅助线（P1）。MacKay 的路径比 Cover 更偏 inference 与机器学习：第 12–13 讲 Monte Carlo 衔接 100B 实分析与概率论，第 15–16 讲神经网络衔接 Strang 18.065。
