  讲义是教师的书面讲稿（MagicPoint slides），本目录是课堂现场板书的照片扫描；
  两者并列参考，**不是「原版 ↔ 译文」的配对关系**。
- 因此：`orig_map.tsv` 中这 17 条的状态是 **「原始材料」**，不属于「译文缺失」。
